# 프로젝트 요약

이 프로젝트는 제조업 디지털 전환을 원하는 수요기업과 기술을 보유한 공급기업을 자동으로 연결하기 위한 산학협력 프로젝트입니다.

## 배경

제조업 DX 매칭에서는 수요기업의 업종, 기업 소개, 기술 요구를 바탕으로 적합한 솔루션 또는 특허 기술을 가진 공급기업을 찾아야 합니다. 하지만 기업 기본 정보만으로는 필요한 기술이 명확하게 드러나지 않는 경우가 많았습니다.

## 접근 전환

초기 접근은 기업과 기업을 직접 매칭하는 방식이었습니다. 이후 데이터 검토를 통해 기업 단위 직접 비교보다 기술 단위 검색이 더 적합하다고 판단했습니다.

최종 구조는 다음과 같습니다.

1. 수요기업 설명을 기반으로 필요한 기술 수요를 표현한다.
2. 공급기업의 특허·솔루션 설명과 의미 유사도를 계산한다.
3. 유사 기술을 보유한 공급기업을 후보로 집계한다.
4. 기술 적합도와 기업 신뢰도를 함께 반영해 최종 추천한다.

## 주요 결과

- 폐업·휴업 기업 596개 제거
- 최종 4,711개 행, 4,623개 기업 분석 대상 확보
- KR-SBERT 기반 한국어 기술 설명 임베딩
- FAISS 기반 유사 기술 후보 검색
- 기술 적합도 80%, 기업 신뢰도 20%의 점수화 모델 설계
- 추천 결과를 HTML 형태로 시각화
