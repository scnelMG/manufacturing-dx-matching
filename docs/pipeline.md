# 매칭 파이프라인

## 1. 기업 데이터 전처리

원본 기업 데이터에는 공급기업과 수요기업이 혼재되어 있었고, 폐업·휴업 기업도 포함되어 있었습니다. 사업자 상태와 중복 기업 정보를 정리해 최종 분석 대상을 구성했습니다.

기업 소개가 부족한 경우에는 홈페이지 본문을 수집하고 LLM을 활용해 기업 정체성을 요약했습니다. 이 단계는 수요기업 임베딩의 품질을 높이기 위한 보강 작업이었습니다.

## 2. 기술 데이터 통합

공급기업이 보유한 특허, 제품, 솔루션 정보를 하나의 기술 설명 단위로 통합했습니다. 서로 다른 출처의 기술 정보를 기업명 기준으로 연결하고, 임베딩 대상 문장을 구성했습니다.

## 3. 임베딩

수요기업 설명과 공급 기술 설명을 KR-SBERT로 벡터화했습니다.

사용 모델:

```text
snunlp/KR-SBERT-V40K-klueNLI-augSTS
```

## 4. 유사 기술 검색

FAISS를 사용해 수요기업 벡터와 공급 기술 벡터 간 유사도를 계산했습니다. 수십만 개 기술 후보 중 상위 후보군을 빠르게 탐색하기 위해 벡터 검색 구조를 적용했습니다.

## 5. 기업 단위 점수화

유사 기술 후보를 기업 단위로 집계한 뒤 최종 점수를 계산했습니다.

```text
최종 점수 = 기술 적합도 * 0.8 + 기업 신뢰도 * 0.2
```

- 기술 적합도: 유사 기술의 평균 유사도와 보유 기술 개수 반영
- 기업 신뢰도: 인증 및 수상 이력을 log 변환해 반영

## 6. 결과 시각화

최종 추천 기업과 매칭된 기술 후보를 HTML 페이지로 시각화했습니다. 공개 저장소의 데모는 실제 기업명과 세부 기술명을 비식별 처리한 버전입니다.
