# 공개 안전성 검토

## Drive 매칭 결과

Google Drive에서 기업 데이터 정제 Excel, 전처리 파일, 참고 논문 PDF가 확인되었습니다.

## 공개 제외 기준

- 사업자등록번호, 연락처, 주소 등 기업 식별 정보가 포함될 수 있는 원본 Excel
- 대용량 임베딩 파일
- 크롤링 원문과 LLM 생성 중간 산출물
- 라이선스 확인이 필요한 참고 PDF 원문

## 공개 유지 자료

- 비식별 샘플 CSV
- 비식별 매칭 결과 HTML
- 파이프라인, 모델 선택, 한계 문서

이 저장소는 실제 기업 정보를 보여주는 것이 아니라, 수요-공급기업 매칭 알고리즘의 설계와 의사결정 과정을 보여주는 포트폴리오입니다.
