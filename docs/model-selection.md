# 임베딩 모델 선택

## 문제

매칭 품질은 수요기업 설명과 공급 기술 설명 사이의 의미적 유사도를 얼마나 잘 계산하는지에 크게 좌우되었습니다. 데이터에는 한국어 제조업, 특허, 솔루션 설명이 섞여 있어 모델 선택이 핵심 의사결정이었습니다.

## KorPatBERT 실험

처음에는 특허 문헌으로 학습된 KorPatBERT를 검토했습니다. 도메인 특화 모델이므로 특허 설명에 강할 것이라고 예상했습니다.

하지만 예시 문장 간 유사도를 확인한 결과, 의미적으로 관련 없는 문장들도 높은 유사도를 보이는 문제가 있었습니다. 유사도 분포의 차이가 충분히 나타나지 않아 최종 매칭 모델로 사용하기 어렵다고 판단했습니다.

## SciBERT/SPECTER 계열 검토

과학 논문 기반 영어 모델도 검토했습니다. 다만 한국어 데이터를 영어로 번역해야 했고, 전체 번역 예상 시간이 약 160시간으로 추정되어 프로젝트 기간 내 적용이 어려웠습니다.

## 최종 선택: KR-SBERT

최종적으로 한국어 문장 간 의미 유사도 측정에 적합한 KR-SBERT를 선택했습니다.

선택 이유:

- 한국어 문장 임베딩 목적에 직접적으로 적합
- 별도 번역 단계가 필요 없음
- 수요기업 설명과 공급 기술 설명을 같은 벡터 공간에서 비교 가능

사용 모델:

```text
snunlp/KR-SBERT-V40K-klueNLI-augSTS
```

## 배운 점

도메인 특화 모델이라는 이름만으로 실제 문제에 적합하다고 볼 수는 없었습니다. 모델 선택은 사전 가정이 아니라 데이터에서 유사도 분포와 결과 품질을 확인하면서 결정해야 했습니다.
